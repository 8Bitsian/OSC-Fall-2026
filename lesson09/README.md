### ℹ️ Introduction
> Firewalls provide a security border around a network, but this secure border is not sufficient to protect against insider threats, advanced malware, or sophisticated threat-actor tactics and techniques.
> Most organizations deploy defense in depth controls to ensure that each endpoint—computer, laptop, smartphone, or tablet—is deployed in a hardened configuration in terms of both the OS and the web browser software.

### #️⃣ Certification Preparation
> This lesson prepares me for the following topics in the ![CompTIA A+ Core 2][CORE] Certification:
> - Configuring workstation security
> - Configuring browser security
> - Troubleshooting workstation security issues
