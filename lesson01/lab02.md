# Lab: Close a Ticket
Your name is **Jamie Anderson**, and you work in the IT department for a small company.
An employee by the name of **Taylor Quick** assigned you a help desk ticket requesting that the software program named **Audacity** be installed on her system.
You installed the program after work hours yesterday, and you need to update the ticket accordingly.

## Directions
In this lab your task is to:
- Open the company's help desk ticketing system, **Issue Trax**
- For the ticket assigned to you, add the following comment and close the ticket using the following information:
  - **Taylor, I installed Audacity on your system last night.**
- Verify that the closed ticket is showed under the **Closed** category of the ticketing system

## Explanation
Complete this lab as follows:
1. From **Office1**, open the company's help desk ticketing system, **Issue Trax**:
  - From the taskbar, select **Start**
  - Select **All apps**
  - Select **Issue Trax**
2. Close the ticket created by **Taylor Quick** requesting that Audacity be installed:
  - From the right pane, select **12 - Need Audacity installed**
  - In the **New Comment** field, enter the comment
  - Select the **plus sign (+)** to add the comment
  - From the top of the ticket:
    - Select **Save**
    - Select the **left arrow (<-)**
3. Verify that the ticket is closed:
  - From the left pane, select **Closed**
  - Verify that **12 - Need Audacity installed** is shown
