# ⏹️ Types of Operating Systems
You have been assigned a new trouble ticket. This ticket is for a new server that runs the Linux operating system.
You have not used Linux and this causes an uneasy feeling as you gather your tool bag and contact the customer needing support.
While you are very familiar with the Windows operating system, Linux brings a new flavor to the enterprise environment.

Once on site, you set the server up and boot it for the first time. It boots and a login screen appears.
You are unsure of the credentials to log in, so you conduct research online and in the owner's manual.
You have the credentials and log in. The logon process completes and a simple black screen appears with white text.
Now the fun can begin as you learn how to configure the server with a brand new operating system.
