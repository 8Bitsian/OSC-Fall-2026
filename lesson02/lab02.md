# Lab: Configure Windows Update
You are the IT administrator for a small corporate network. The company recently experienced some security incidents, prompting a review and configuring Windows Update settings where needed.

## Directions: 
In this lab, your task is to:
- Complete the following on **Office1**:
  - Access Windows Update settings and select **Check for updates**
  - Configure Windows Update to include updates for other Microsoft products when you update Windows
  - Set the Windows Update active hours for Office1 from **6:00 AM to 6:00 PM**

## Explanation
1. From Office1, access Windows Update settings:
  - From the taskbar, select **Start**
  - Select **Settings** and navigate left pane for **Windows Updates**
  - Select Check for updates and wait for updates to download and install
2. Configure Windows Update to include updates for other Microsoft products when you update Windows
  - From the Windows Update settings, scroll down and select Advanced options
  - For Receive updates for other Microsoft products, slide the toggle switch to On
3. Set the Windows Update active hours for Office1 from 6:00 AM to 6:00 PM.
  - From the Windows Update settings, scroll down and select Advanced options if you are not already there
  - Select Active hours.
  - Select a value in the current Start time.
  - In the left column, select 6 and it should indicate the start time to be 6:00 AM.
  - Select the checkmark.
  - Select a value in the End time.
  - In the left column, select 6 and it should indicate the end time to be 6:00 PM
  - Select the checkmark.
