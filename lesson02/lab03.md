# Lab: Create Azure Storage Account
You are the network administrator for your company.
You are configuring Azure to help manage your network.
You are synchronizing on-premise files to the cloud.
The next step is to create an Azure Storage Account with a File Share to sync the files to.

## Directions
In this lab your task is to:
- Create a storage account with the following options:
  - Subscription: **CorpNet Production**
  - Resource group: **CorpNetCloud**
  - Storage account name (case sensitive): **corpnetstorageaccount**
  - Region: **(US) West US2**
  - Redundancy: **Geo-redundant storage (GRS)**
- Create a file share named **corpnetfileshare** from within the storage account you created

## Explanation
Complete this lab as follows:
1. To create a storage account:
- In the Azure portal, select Storage accounts under Azure Services.
- Select +Create.
2. To create a file share:
- When the storage account deployment is complete, select Go to resource.
- In the left navigation pane, select File shares.
- Select +File share.
